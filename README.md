continuaçao do projeto web com correções

### Sobre
Estrutura Mínima do Site 
Telas institucionais: 4 páginas 
1. Home (index.html) 
o Apresentação institucional do curso de Odontologia. 

o Banner principal com destaque visual. 

o Breve descrição dos diferenciais do curso. 

o Botões ou links para outras páginas. 

2. Professores (professores.html) 
o Listagem dos professores com foto, nome, formação e área de atuação. 

o Dados podem ser estáticos ou carregados dinamicamente via JSON. 

o Opção extra (caso desejem implementar): botão "Ver mais" com modal. 

3. Cursos (curso.html) 
o Lista de Vantagens do curso. 

o Grade Curricular. 

o Laboratórios. 

4. Contato (contato.html) 
o Formulário com campos: nome, telefone, e-mail, assunto e mensagem. 

o Envio com mensagem de confirmação. 

o Pode conter mapa da localização do campus (Google Maps). 

Telas Funcionais: 2 páginas  

1. Tela de Login do Professor (login.html) 
o Formulário com campos de e-mail e senha. 

o Simulação de autenticação (sem necessidade de back-end real). 

o Redirecionamento para a Área do Professor. 

2. Área do Professor (dashboard.html ou area-professor.html) 
o Tela protegida após o login. 

o Deve exibir: 
1. Nome do professor 

2. Links para consultar dados do curso e outros professores

3. Botão de logout
